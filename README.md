# SugarCRM on Docker

Supports version `v25.1.x`.

- Apache 2.4
- PHP 8.4
- MySQL 8.4
- OpenSearch 2.19.0

https://support.sugarcrm.com/resources/supported_platforms/#Sugar_25.1.x_Supported_Platforms

## Usage

```
git clone https://github.com/rythgs/sugar-docker-example.git
cd sugar-docker-example
docker-compose up -d
```

`./src` is Document Root.  
Put source code here.
